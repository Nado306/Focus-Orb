Browser link

Window titles only tell the orb so much. This small Chrome and Edge extension tells it the address of your active tab, so a rule like url:x.com can't be fooled by a vague page title.

Setting it up

  1. 1
    Turn the link on, then press Open extension folder below.
  2. 2
    Go to edge://extensions in Edge or chrome://extensions in Chrome, and switch on Developer mode.
  3. 3
    Choose Load unpacked and pick the folder that opened. It's called Focus Orb link.
  4. 4
    Within a few seconds the status above says Connected.

What it can see

  • The address and title of your active tab, sent only to 127.0.0.1, this computer.
  • When you open a new address in any tab, it asks the orb whether to block it. The answer is only ever yes with Block sites during focus switched on in Settings.
  • The orb keeps them in memory for matching and never writes them to disk. A drift in the browser is recorded by the site's name, such as youtube.com, never the full address.
  • For a second browser, load the same folder.
